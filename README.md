# 🦇 Misión Kabal: Los Dos Nightwings (Especial para María) 💙🧡

Un juego web interactivo creado por **Albert** especialmente para **María**, inspirado en la noche del 31 de octubre en Kabal (Las Mercedes) donde ambos coincidieron con el cosplay de **Nightwing**.

## 🌟 Características
- **Estética Nightwing & Atardecer**: Paleta azul eléctrico (`#0080FF`) y naranja cielo (`#FF6B35`).
- **Foto Real de Ambos**: Muestra la foto de Albert y Mari en su cosplay de Nightwings en la pantalla inicial y final.
- **7 Misiones / Minijuegos Interactivos**:
  1. *Activa los Bat-Emblemas*: Destellos nocturnos en Kabal.
  2. *El Dúo Dinámico*: Juego de memoria con íconos de su historia (sushi, switch, audífonos, nightwing...).
  3. *Atrapa el Sushi de la Chef*: Mini-juego de atrapar sushi en la tabla de chef.
  4. *Sopa de Letras de Nuestra Historia*: Palabras clave como NIGHTWING, KABAL, SUSHI, VALENCIA, ALBERT, MARI, AZUL.
  5. *El Brillo de su Cabello Azul*: Mini-juego deslizante inspirado en su cabello liso azul Universe Lycan.
  6. *El Naranja del Atardecer*: Arrastrar estrellas del cielo naranja (su color favorito) al frasco de la noche.
  7. *La Carta Encriptada*: Raspa el holograma para leer la carta secreta de Albert.
- **7 Preguntas Secretas para Conocerse**:
  - En cada misión responde una pregunta con opciones interactivas o texto libre.
- **📲 Envío Automático a WhatsApp**:
  - Al completar el juego, un botón genera el mensaje pre-armado con todas sus respuestas listo para enviar a Albert al **04129983853** (`+584129983853`).

## 🚀 Cómo Ejecutar
```bash
# Iniciar servidor de desarrollo
npm run dev

# Generar versión para producción
npm run build
```
